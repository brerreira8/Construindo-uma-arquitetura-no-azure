# Construindo-uma-arquitetura-no-azure

# PASSO A PASSO PARA CONSTRUIR UMA ARQUITETURA BÁSICA NO AZURE

* CRIAÇÃO DO AMBIENTE
  - CRIE UM GRUPODE RECURSOS (RESOURCE GROUPS)
  - ESCOLHA UMA REGIÃO (DATACENTER) PENSANDO NO MAIS PRÓXIMO DO SEUS USUÁRIOS PARA TER UMA LATÊNCIA MENOR.

# CAMADA DE COMPUTAÇÃO
 
* PARA ALGO SIMPLES UTILIZE O APP SERVICE (PAAS).
* CASO QUEIRA CONTROLE TOTAL CRIE UMA MÁQUINA VIRTUAL (VM).
* PARA ALGO MODERNO UTILZIE O AZURE KUBERNETS SEFICE (AKS) OU AZURE FUNCTIONS.

# CAMADA DE DADOS
 - BANCO DE DADOS RELACIONAL ESCOLHIDO: AZURE SQL DATABASE.
 - ARMAZENAMENTO DE ARQUIVOS: AZURE BLOB STORAGE

# REDE E SEGRUANÇA
 - VIRTUAL NETWORK (VNET) PARA COMUNICAÇÃO ENTRE RECURSOS.
 - UTULIZE AZURE FIREWALL PARA O TRÁFEGO PROTEGIDO.
